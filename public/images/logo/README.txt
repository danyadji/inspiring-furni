FOLDER LOGO INSPIRING FURNI
=============================

Tempat menyimpan file logo website Inspiring Furni.

Panduan:
1. File default yang saat ini digunakan di Navbar adalah:
   public/images/logo/logo.svg

2. Jika Anda punya file logo sendiri (format PNG, SVG, JPG, atau WEBP):
   - Anda dapat menaruh file logo Anda di folder ini (misalnya: `logo.png` atau `logo.svg`).
   - Jika Anda mengganti nama atau menggunakan `logo.png`, sesuaikan path di file `src/components/Navbar.tsx`.
   - Atau Anda bisa langsung me-replace / menimpa file `logo.svg` yang ada di folder ini dengan file logo SVG Anda.

3. Rekomendasi ukuran:
   - Icon / Monogram: 80x80 px (tampil 40x40 px di layar untuk Retina display).
   - Horizontal Logo / Wordmark: tinggi 40-50 px dengan lebar proporsional (transparan / PNG / SVG).
